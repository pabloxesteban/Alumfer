# Published — Registro de Contenido Publicado

> Este directorio es el archivo de todo el contenido publicado. Permite análisis histórico, referencia para campañas futuras, y tracking de performance.

---

## Por qué mantener este registro

- Evitar repetir exactamente el mismo tipo de contenido en poco tiempo
- Tener referencia de qué obras ya fueron publicadas (para no publicar la misma obra dos veces)
- Poder comparar performance de distintos tipos de contenido
- Referencia para el análisis mensual (campaign-planning.md → Paso 7)

---

## Naming convention

`YYYYMMDD-[producto]-[barrio]-PUB.md`

Ejemplo: `20240825-dvh-quilmes-PUB.md`

El sufijo `-PUB` indica que ya fue publicado.

---

---

## Estructura de subdirectorios recomendada

A medida que el archivo crece, organizar por año y mes:

```
published/
  2024/
    07-julio/
    08-agosto/
    ...
  2025/
    ...
```

---

## Flujo

```
approved/ → (publicado) → published/
published/ → (análisis a los 7 días) → datos en el dashboard mensual
```
