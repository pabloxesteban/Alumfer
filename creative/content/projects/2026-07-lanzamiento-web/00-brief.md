# 00 · Brief — Lanzamiento del Nuevo Sitio Web de Alumfer

> Punto de entrada al engine. Lo recibe el Orchestrator (Director Creativo Senior).
> Regla base: no aceptar la primera idea. La primera idea de un lanzamiento web es siempre "tenemos página nueva" — y eso está prohibido por diseño (`engine/prohibitions.md` #1 y #8).

## Datos del proyecto
- **Marca:** Alumfer — carpintería de aluminio premium, fábrica propia en Adrogué, Zona Sur GBA.
- **Evento a comunicar:** lanzamiento del nuevo sitio web oficial (`alumfer.com.ar`).
- **Plataforma:** Instagram.
- **Formato:** a decidir por el Creative Strategist (carrusel / historia / post estático). **No asumir carrusel.**
- **Mercado:** Gran Buenos Aires (Zona Sur), Argentina.
- **Idioma:** Español rioplatense (argentino, GBA).

## Objetivos
**Principal:** presentar el nuevo sitio web de Alumfer.

**Secundarios (en orden de peso para este brief):**
1. Transmitir **evolución y profesionalismo** (la marca creció, no improvisó).
2. Generar **confianza** y reforzar posicionamiento **premium**.
3. Aumentar **reconocimiento de marca**.
4. Incentivar **visitas al sitio** (tráfico calificado, no vanidad).
5. Mostrar una empresa **moderna y cercana** a la vez.

## Restricciones (cargadas como kill-switches del engine)
- **PROHIBIDO** el mensaje literal "tenemos una web nueva" / "visitá nuestra página" como eje. Es el ángulo obvio → muere en Fase 2.
- No sonar corporativo ni a agencia de marketing (F04). El que habla es el artesano, no el community manager.
- No estética de inmobiliaria genérica (pedido explícito del brief).
- Anclaje a Zona Sur GBA y a obra propia (kill-switch R01).
- Debe detener el scroll. Debe sentirse hecho por una agencia creativa de arquitectura/diseño.
- Sin urgencia falsa, sin descuentos, sin precio como argumento.

## Tensión del brief (la trampa a resolver)
Un lanzamiento de sitio web es, para el usuario de Instagram, **el contenido más ignorable que existe**: a nadie le importa que una carpintería tenga web nueva. El reto no es "avisar del sitio". El reto es encontrar el ángulo por el cual alguien —que no vino a que le vendan una web— **se detiene, siente algo y termina queriendo asomarse**. Si la pieza se puede resumir en "novedad de la empresa", fracasó.

## Métrica objetivo (orden de prioridad)
```
1. VISITAS AL SITIO (clics a link en bio)   → conversión primaria del lanzamiento
2. GUARDADOS                                → intención diferida (el que va a renovar)
3. DMs / consultas por WhatsApp             → intención de compra
4. COMPARTIDOS                              → alcance calificado (viaja a quien decide)
—  Likes / follows                          → vanidad, se ignora
```

## Fase 0 — Memoria cargada (antes de explorar)
El Orchestrator leyó de `creative/knowledge/` y `creative/brand/`:
- **`brand/brand-dna.md`** → arquetipo Artesano + Gobernante; "no vende ventanas, vende transformar un espacio".
- **`brand/emotional-positioning.md`** → emoción central **Confianza Tranquila**; en IG, **Aspiración Alcanzable**.
- **`engine/prohibitions.md`** → #1 genérico, #3 no anunciar el tema, #8 clichés ("transformamos tu hogar").
- **`analytics` / `knowledge/failed-content`** → F01 (viral sin localización), F04 (post corporativo) a evitar.
- **`brand/storytelling.md`** → toda pieza Alumfer es un arco de transformación (antes → oficio → después).

**Resumen que condiciona la exploración:** Alumfer fabrica ventanas —el objeto cuya función es *dejar ver y dejar pasar la luz sin dejar pasar lo malo*. Un sitio web cumple exactamente esa función en digital: **es una ventana a la fábrica**. La marca tiene una metáfora propia, intransferible, que ningún competidor puede robar. El territorio más fértil no es "novedad tecnológica" (frío, corporativo) sino **"abrimos una ventana"**: mismo oficio, misma exigencia del taller, ahora también en la pantalla. El lanzamiento se cuenta como **evolución, no como reinvención**.
