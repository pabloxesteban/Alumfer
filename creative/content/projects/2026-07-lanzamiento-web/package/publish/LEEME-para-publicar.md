# Post listo para Instagram — "Una ventana más"

Carrusel de 8 imágenes (1080×1080). Subí `slide-1.png` … `slide-8.png` **en orden**.

## Pasos
1. Instagram → **+** → seleccioná las 8 imágenes en orden (1→8).
2. Pegá el **texto (caption)** de abajo.
3. Publicá.
4. Apenas se publica, dejá el **primer comentario** con los hashtags.
5. Fijá (pin) el **comentario fijado**.
6. Revisá que el **link en la bio** apunte a `alumfer.com.ar`.
