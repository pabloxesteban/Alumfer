# References — Estilo visual del carrusel gráfico

> Drop-point de referencias para darle más estilo a las 8 slides ilustradas (`../package/slides/`).
> Todo lo que se suelte acá alimenta la memoria creativa (`creative/knowledge/swipe-file/`).

## Cómo dejar referencias
- **En el chat:** adjuntar/pegar las imágenes directamente (lo más rápido).
- **En esta carpeta:** subir los archivos `.jpg/.png` acá (quedan versionados en el repo).
- **Nombrarlas** para que sepa qué mirar de cada una, ej.:
  ```
  ref-01_paleta.jpg          → mirar el color / mood
  ref-02_tipografia.png      → mirar el tratamiento de tipo
  ref-03_layout-editorial.jpg→ mirar la composición / grilla
  ref-04_textura-grano.jpg   → mirar la textura / grano
  ref-05_iconos-linea.png    → mirar el estilo de line-art
  ```

## Qué me sirve indicar de cada referencia (elegí lo que aplique)
- **Color / mood** — la paleta o el clima que querés.
- **Tipografía** — pesos, tamaños, mayúsculas, tracking, display vs. cuerpo.
- **Composición / grilla** — cómo se ordena, aire, asimetría, márgenes.
- **Textura** — grano, ruido, papel, degradados, "blueprint" técnico.
- **Line-art / iconografía** — grosor de línea, nivel de detalle, estilo de dibujo.
- **Qué NO copiar** — para no cruzar la línea del plagio (solo tomamos estructura).
