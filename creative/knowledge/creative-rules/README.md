# Creative Rules — Reglas Creativas Aprendidas

> El destilado del sistema. Lo que Alumfer sabe que funciona, respaldado por evidencia.
> Se lee SIEMPRE al inicio del loop. Es lo primero que consulta el Orchestrator.

---

## Cómo se usa
- **Se lee** al comienzo de cada pieza (Fase 0). Estas reglas condicionan toda la exploración.
- **Se escribe** cuando `learning/feedback-loop.md` valida un patrón con evidencia real (mínimo 2-3 piezas coincidentes).

## Jerarquía de certeza
```
LEY        → validada con mucha evidencia; violarla exige justificación explícita.
REGLA      → validada con evidencia suficiente; default fuerte.
HIPÓTESIS  → derivada de principios o de una sola pieza; a validar.
```

## Esquema de una regla
```
ID: R[nn] · NIVEL: ley | regla | hipótesis
REGLA: [enunciado accionable en una línea]
POR QUÉ: [el mecanismo]
EVIDENCIA: [piezas de successful/failed que la respaldan]
DESDE: [YYYY-MM] · REVISADA: [YYYY-MM]
```

## Reglas iniciales (derivadas de `brand/` y `analytics/`, nivel base)

### R01 · LEY — Anclar a Zona Sur siempre
Toda pieza debe poder anclarse a Zona Sur GBA u obra propia. **Por qué:** el viral sin localización no genera consultas. **Evidencia:** F01. Kill-switch en gates.

### R02 · LEY — Captar antes de aportar antes de convertir
Nunca invertir el orden. **Por qué:** empezar por el valor o la venta pierde a la persona antes de frenarla. **Evidencia:** principio de `prohibitions.md`.

### R03 · REGLA — El dato concreto vence al adjetivo
"6 grados de diferencia" > "mucho más cálido". **Por qué:** el dato hace imaginable el beneficio y se guarda. **Evidencia:** `analytics/success-patterns.md` P2.

### R04 · REGLA — El proceso construye confianza
Mostrar el taller/oficio convierte al que está evaluando entre dos carpinterías. **Evidencia:** P3.

### R05 · REGLA — El antes honesto genera identificación
Mostrar el problema real (no solo el resultado perfecto) hace que el cliente se reconozca. **Evidencia:** P5.

### R06 · REGLA — Guardados y DMs pesan más que views
Para Alumfer, intención > alcance. **Por qué:** el cliente decide en semanas; el contenido siembra. **Evidencia:** `north-star-metric.md`.

### R07 · HIPÓTESIS — La confesión ("lo que no te cuentan") genera comentarios
A validar con piezas reales del ángulo confesión.

### R08 · HIPÓTESIS — El humor seco diferencia en un rubro solemne
El rubro es serio y aburrido; el humor con criterio podría destacar. A validar.

---

## Regla sobre las reglas
- Una hipótesis sube a regla solo con evidencia (2-3 piezas). Una regla sube a ley con evidencia sostenida.
- Las reglas se **revisan**: si `learning/` muestra que dejó de funcionar, se degrada o se archiva con fecha (no se borra).
- Toda promoción/degradación se registra en `creative-decisions/`.
