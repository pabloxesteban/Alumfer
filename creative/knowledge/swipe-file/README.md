# Swipe File — Referencias Externas para Robar (Estructura, no Copia)

> Inspiración de afuera del rubro. Robamos la estructura, nunca la ejecución.
> El mejor contenido de aberturas se inspira en marcas que no venden aberturas.

---

## Robar estructura ≠ plagiar
- **Robar estructura** (sí): "cómo Apple genera deseo mostrando un detalle en macro y silencio" → aplicar la mecánica a un herraje.
- **Plagiar ejecución** (no): copiar el guión, la música o el formato con marca de agua de otro.

El Creative Challenger vigila la línea: si una idea es "lo que ya hizo [marca]" en ejecución, muere. Si es "la mecánica de [marca] aplicada a algo nuevo de Alumfer", vale.

## Cómo se usa
- **Se lee** cuando la exploración necesita salir del rubro para no sonar a rubro.
- **Se escribe** cuando se encuentra una referencia potente afuera.

## Esquema
```
REFERENCIA: [marca/creador/pieza]
QUÉ HACE BIEN: [el mecanismo]
ESTRUCTURA ROBABLE: [qué se puede transferir]
APLICACIÓN ALUMFER: [cómo se traduce al rubro]
NO COPIAR: [qué es propio de ellos y no se toca]
```

## Referencias sembradas (conectan con `knowledge/*.md` de V1)

### Apple — deseo por restricción
**Mecanismo:** macro + silencio + una sola idea por pieza. **Robable:** mostrar un detalle mínimo (esquina a 45°) sin explicar, dejar que la calidad hable. **Aplicación:** copywriter premium. **No copiar:** su minimalismo frío total; Alumfer tiene calidez de oficio. (Ver `knowledge/apple-brand-analysis.md`.)

### Aesop — lenguaje que eleva lo cotidiano
**Mecanismo:** describir lo funcional con precisión casi literaria. **Robable:** hablar de materia y luz, no de "productos". **Aplicación:** premium, metáforas. (Ver `knowledge/aesop-brand-analysis.md`.)

### Nike — el cliente es el héroe
**Mecanismo:** la marca es el guía, nunca el protagonista. **Robable:** estructura "cliente héroe" del Story Architect. **Aplicación:** casos reales. (Ver `knowledge/nike-storytelling.md`.)

### Tesla — el dato como espectáculo
**Mecanismo:** convertir una spec en un momento de asombro. **Robable:** "6 grados de diferencia" mostrado, no dicho. **Aplicación:** ángulo dato curioso / problema invisible. (Ver `knowledge/tesla-positioning.md`.)

### Creadores de oficio (carpintería/herrería de nicho)
**Mecanismo:** el proceso hipnótico, el ASMR del trabajo bien hecho. **Robable:** primerísimos planos de corte, soldadura, verificación. **Aplicación:** ángulo proceso, hooks visuales/audio.

## Regla
Toda referencia se traduce al territorio Alumfer (El Artesano, Zona Sur, industrial elegante). Una referencia sin traducción no entra al swipe file: entraría al plagio.
