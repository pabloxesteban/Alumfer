# Analogies — Analogías Reutilizables

> Herramientas para hacer entendible lo técnico.
> Una buena analogía convierte una spec aburrida en un "ahá". El copywriter educativo y el Story Architect sacan de acá.

---

## Cómo se usa
- **Se lee** cuando hay que explicar algo técnico de forma memorable.
- **Se escribe** cuando se crea una analogía que "pega" (el cliente la entiende y la repite).

## Esquema
```
CONCEPTO TÉCNICO: [qué se quiere explicar]
ANALOGÍA: [con qué cotidiano se compara]
POR QUÉ FUNCIONA: [qué hace clic]
DÓNDE USARLA: [tipo de pieza]
```

## Analogías sembradas

### DVH (doble vidriado hermético)
**Analogía:** "Es como una campera de dos capas con aire adentro. No abriga la tela: abriga el aire quieto entre las capas." **Funciona:** todos entienden por qué una campera inflada abriga más que una remera gruesa. **Usar en:** educativo sobre DVH.

### Ruptura de puente térmico en el marco
**Analogía:** "Un marco sin corte térmico es como agarrar una olla caliente con una cuchara de metal: el frío/calor viaja por el material hasta tu mano. El corte térmico es el mango de madera." **Funciona:** experiencia física universal. **Usar en:** explicar por qué el marco importa tanto como el vidrio.

### Sellado perimetral
**Analogía:** "Podés tener la mejor puerta del mundo, pero si queda un dedo de luz abajo, entra frío igual. La ventana es lo mismo: el sellado es esa rendija." **Funciona:** todos sintieron el frío por debajo de una puerta. **Usar en:** por qué la instalación importa tanto como el producto.

### Fabricación a medida vs. estándar
**Analogía:** "Comprar una ventana estándar y forzarla al vano es como comprar un traje de talle único: entra, pero se nota. A medida entra exacto." **Funciona:** la ropa a medida es un símbolo de calidad conocido. **Usar en:** premium, diferenciación.

### Vidrio de seguridad (templado / laminado)
**Analogía:** "El templado, si se rompe, se hace granza como el parabrisas: no corta. El laminado queda pegado como el vidrio de un banco. Elegís según el riesgo." **Funciona:** referencias cotidianas (auto, banco). **Usar en:** FAQ de seguridad.

## Regla
Una analogía es buena si el cliente la puede repetir después. Si necesita explicación, no sirve. Se prueban en piezas reales y se marca cuáles el público adopta (aparecen en comentarios).
