# Storytelling — Estructuras Narrativas

> El Story Architect saca de acá.
> Ninguna pieza es una lista de información: toda pieza tiene una de estas estructuras.

---

## Cómo se usa
- **Se lee** cuando el Story Architect arranca.
- **Se escribe** cuando una estructura funciona repetidamente (se anota su tasa de éxito) o cuando se descubre una nueva.

## Las 7 estructuras base

### 1 · Problema → Agitación → Solución
Mostrar el dolor → hacerlo doler más (consecuencias) → resolver. **Para:** objeciones, miedos. **Alumfer:** "tu ventana filtra → mirá cuánto gas se va y cómo se arruina el marco por dentro → así lo resolvemos".

### 2 · Antes → Giro → Después
Estado previo → el momento que cambia todo → resultado. **Para:** transformaciones de obra. **Alumfer:** la transición antes/después ES el pico de impacto (`analytics/success-patterns.md` P5).

### 3 · Loop abierto
Plantear pregunta/misterio → retenerlo → cerrarlo al final. **Para:** watch time, curiosidad. **Alumfer:** "hay una razón por la que tu ventana nueva sigue filtrando… te la mostramos al final".

### 4 · Cliente héroe
El cliente tiene un problema → Alumfer es el guía → el cliente gana. **Para:** casos reales, prueba social. **Alumfer:** el cliente es el protagonista, Alumfer nunca se roba la escena.

### 5 · Mito → Verdad
Creencia común → por qué es falsa → qué es cierto. **Para:** educativo con tensión. **Alumfer:** "'el problema es el vidrio' → falso → casi siempre es el marco y el sellado".

### 6 · Detalle → Sistema
Un detalle mínimo revela una filosofía entera. **Para:** premium, proceso. **Alumfer:** "la esquina donde se juntan dos perfiles dice si todo lo demás está bien hecho".

### 7 · Costo oculto
Lo que parece barato → lo que en realidad cuesta → la alternativa correcta. **Para:** ventas, objeción de precio. **Alumfer:** la ventana barata que se cambia a los 3 años.

## Esquema de un esqueleto (lo que produce el Story Architect)
```
ESTRUCTURA: [una de las 7]
BEAT 1 — TENSIÓN (0-2s): [arranca en el conflicto]
BEAT 2 — DESARROLLO: [...]
BEAT 3 — GIRO: [momento de mayor impacto]
BEAT 4 — RESOLUCIÓN + PRUEBA: [dato/obra real]
BEAT 5 — INVITACIÓN: [CTA integrado]
ARCO EMOCIONAL: [de X a Y]
```

## Reglas
- Arrancar en la tensión, nunca en el contexto.
- Un solo giro claro por pieza.
- El dato vive dentro de la historia, nunca como bullet suelto.
- Se conecta con `templates/storytelling-formulas.md` (V1), que se mantiene como material de apoyo.
