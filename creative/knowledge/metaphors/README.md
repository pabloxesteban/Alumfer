# Metaphors — Metáforas de Marca

> Distinto de las analogías (que explican).
> Las metáforas elevan y emocionan. Son el lenguaje del copywriter premium y storytelling.

---

## Analogía vs. metáfora en este sistema
- **Analogía** (`analogies/`): "el DVH es como una campera de doble capa" → hace **entender**.
- **Metáfora** (acá): "una ventana es la frontera entre tu casa y el mundo" → hace **sentir**.

## Cómo se usa
- **Se lee** cuando la emoción objetivo es deseo, orgullo o aspiración.
- **Se escribe** cuando se acuña una metáfora potente y de marca.

## Esquema
```
METÁFORA: [la imagen]
QUÉ ELEVA: [qué eleva de un producto funcional a algo con significado]
TERRITORIO: [dentro del ADN de marca — El Artesano]
USAR EN: [premium / storytelling]
CUIDADO: [cuándo suena cursi]
```

## Metáforas sembradas

### La ventana como umbral de luz
"No cambiás una ventana. Cambiás cómo entra la mañana a tu casa." **Eleva:** de abertura a experiencia diaria. **Territorio:** transformación del espacio (brand-dna). **Cuidado:** no abusar de "luz"; una vez por pieza.

### El detalle como firma
"Cada esquina a 45° es una firma. Dice quién lo hizo y cómo trabaja." **Eleva:** el detalle técnico a identidad y orgullo del oficio. **Territorio:** El Artesano. **Usar en:** premium, proceso.

### La casa como frontera
"Tu casa es lo único que separa el ruido de afuera del silencio de adentro. La ventana es esa línea." **Eleva:** función a refugio. **Usar en:** aislación acústica, storytelling. **Cuidado:** puede sonar grandilocuente; anclar siempre en un beneficio concreto después.

### El invierno como examen
"El invierno es el examen que rinde tu casa todos los años. Se aprueba en marzo, no en julio." **Eleva:** la decisión de compra a previsión inteligente. **Usar en:** ventas de temporada. **Territorio:** confianza directa, sin urgencia falsa.

### Fabricar como criar
"Una ventana bien hecha no se arma: se cría. Se corta, se mide, se prueba, se corrige." **Eleva:** producción a cuidado artesanal. **Usar en:** proceso, autoridad. **Cuidado:** que no suene pretencioso; funciona con imagen de taller real.

## Regla
La metáfora eleva pero nunca reemplaza el hecho. Después de emocionar, siempre aterriza en algo concreto (obra real, dato real). Metáfora sin sustancia = cliché, y el cliché está prohibido.
