# Successful Content — Piezas que Funcionaron (y Por Qué)

> El archivo de lo que ganó.
> No para copiar la pieza, sino para entender el mecanismo que se puede repetir.

---

## Cómo se usa
- **Se lee** al planificar una pieza similar: ¿qué mecanismo activó el éxito?
- **Se escribe** cuando una pieza publicada **supera su predicción** de performance (vía `learning/`).

## Esquema de una entrada
```
PIEZA: [slug] · FECHA: [YYYY-MM] · FORMATO: [reel/carrusel/...]
CONCEPTO: [1 línea]
HOOK USADO: "[texto]" · TIPO: [x]
ÁNGULO: [x] · ESTRUCTURA: [x] · EMOCIÓN: [x] · COPYWRITER: [x]
SCORE PREDICHO: [XX/100]
RESULTADO REAL: retención [x] · guardados [x] · compartidos [x] · DMs [x]
POR QUÉ FUNCIONÓ: [el mecanismo, no la descripción]
QUÉ REPLICAR: [el patrón transferible a otras piezas]
REGLA GENERADA: [si originó una regla en creative-rules/, cuál]
```

---

## Estado inicial
Vacío de piezas reales (el engine recién arranca). Se poblará automáticamente a medida que se publiquen piezas y `learning/` mida resultados.

**Punto de partida heredado:** hasta tener datos propios, el engine usa los 6 patrones documentados en `analytics/success-patterns.md` (V1) como proxy de "contenido que funciona en Alumfer":
1. La obra reconocible por el vecino
2. El dato de beneficio concreto
3. El proceso que nadie muestra
4. La urgencia estacional real
5. El antes honesto
6. El contenido educativo de alta calidad

Cada pieza real que confirme uno de estos lo cita; cada pieza que descubra uno nuevo lo agrega.

## Regla
Una pieza entra acá solo con **resultado real medido**, no con expectativa. Superar la predicción es el criterio de ingreso: eso es lo que enseña algo nuevo sobre la audiencia.
