# Templates: Hooks para Reels

El hook es los primeros 2 segundos. Si no engacha ahí, el algoritmo y el usuario siguen de largo.

## Principio

El mejor hook de Alumfer es **visual**: un detalle de terminación impecable, una apertura de ventana con luz, un portón que cierra perfecto. El audio o texto refuerza, no reemplaza.

---

## Hooks visuales (sin texto)

### Hook de detalle
```
Primer plano extremo de: cerradura, goma de sellado, herraje, vidrio espejado, esquina de perfil.
Luego zoom out lento a la pieza completa.
```
Mensaje implícito: la precisión está en el detalle.

### Hook de transformación instantánea
```
Corte seco: obra en progreso (sin ventana) → obra terminada (con ventana instalada).
Sin transición lenta. El corte ES el impacto.
```

### Hook de luz
```
Ventana cerrada → mano la abre → entra luz. O efecto inverso: desde adentro mirando hacia afuera.
```

---

## Hooks con texto sobreimpreso

### Pregunta directa
```
¿Cuánto ruido entra por tus ventanas actuales?
```
Funciona para reels educativos sobre DVH.

### Dato inesperado
```
Una ventana mal sellada puede subir tu factura de gas 30%.
```
Verifiable, específico, con consecuencia económica.

### El "así se hace"
```
Así fabricamos una ventana corrediza de aluminio.
[Paso 1 al paso 5 en 30 segundos]
```

### El resultado sin contexto
```
Esto es lo que instalamos en [barrio] esta semana.
[Imagen impacta, caption da el contexto]
```

---

## Hooks de audio

### Sonido real de obra
El sonido del aluminio cortándose, la ventana cerrando, la taladradora. Sin música. Solo el oficio.

### Música + silencio
Música ambiental (post-rock instrumental, lo-fi industrial) que corta cuando aparece el texto clave.

---

## Anti-hooks (nunca usar)

```
❌ "¡Hola! Hoy les traemos..."
❌ "En este video vamos a ver..."
❌ "Somos Alumfer y queremos mostrarte..."
❌ Texto de presentación antes de la imagen de impacto
❌ Logo en el primer frame
```
